# Glossary: banking-modernization-with-ai

Acronyms and abbreviations used across this project's documentation (README, articles, slides, templates, diagrams).
COBOL reserved words (COMPUTE, ROUNDED, REDEFINES...), copybook field names (ACCT-*) and diagram node IDs are not listed.

| Acronym | Meaning | Area |
|---|---|---|
| **A/R** | Accountable/Responsible (combined RACI cell). | Governance |
| **ACL** | Anti-Corruption Layer: translation layer that keeps the legacy model from leaking into the new domain model (DDD pattern). | Architecture |
| **ADR** | Architecture Decision Record. | Architecture |
| **AI** | Artificial Intelligence. | AI |
| **API** | Application Programming Interface. | Integration |
| **ASCII** | American Standard Code for Information Interchange (character encoding). | Data |
| **BCBS 239** | Basel Committee on Banking Supervision standard 239: principles for risk data aggregation and risk reporting (data lineage). | Regulation |
| **BR-INT** | Business Rule, Interest family: ID prefix in the rule catalog (e.g. BR-INT-001). | Project |
| **CA-7** | Broadcom (formerly Computer Associates) CA-7 Workload Automation, a mainframe job scheduler. | Mainframe |
| **CCYYDDD** | Century-Year-Day-of-year date format (Julian date) common in COBOL records. | Mainframe |
| **CDC** | Change Data Capture: streaming row-level changes out of a database's log. | Data |
| **CFO** | Chief Financial Officer. | Business |
| **CI** | Continuous Integration. | DevOps |
| **CICS** | Customer Information Control System: IBM's mainframe transaction processing monitor. | Mainframe |
| **CIO** | Chief Information Officer. | Business |
| **COBOL** | COmmon Business-Oriented Language. | Mainframe |
| **COMP-3** | COBOL COMPUTATIONAL-3 usage: packed decimal (two digits per byte, sign in the last nibble). | Mainframe |
| **CSV** | Comma-Separated Values. | Data |
| **DB2** | IBM Db2 relational database (mainframe edition: Db2 for z/OS). | Mainframe |
| **DDL** | Data Definition Language (CREATE/ALTER table statements). | Data |
| **DORA** | Digital Operational Resilience Act: EU Regulation 2022/2554 on ICT risk for financial entities. | Regulation |
| **DR** | Disaster Recovery. | Operations |
| **EBA** | European Banking Authority. | Regulation |
| **EBCDIC** | Extended Binary Coded Decimal Interchange Code: IBM mainframe character encoding (e.g. code page IBM037). | Mainframe |
| **EU** | European Union. | Regulation |
| **FX** | Foreign Exchange. | Banking |
| **GDPR** | General Data Protection Regulation (EU 2016/679). | Regulation |
| **GFM** | GitHub Flavored Markdown. | Tooling |
| **GIF** | Graphics Interchange Format. | Format |
| **HTML** | HyperText Markup Language. | Format |
| **HTTP** | HyperText Transfer Protocol. | Integration |
| **IBM** | International Business Machines. | Vendor |
| **ICT** | Information and Communication Technology (DORA's term for IT systems and third-party providers). | Regulation |
| **ID** | Identifier. | General |
| **IMS** | Information Management System: IBM hierarchical database and transaction manager. | Mainframe |
| **ISO 20022** | International Organization for Standardization standard for financial messaging (XML-based payments messages). | Banking |
| **JCL** | Job Control Language: describes and runs mainframe batch jobs. | Mainframe |
| **JOBOL** | Slang for "Java written like COBOL": line-by-line translation that keeps COBOL structure. | Modernization |
| **JPEG** | Joint Photographic Experts Group image format. | Format |
| **KB / MB / TB** | Kilobyte / Megabyte / Terabyte. | General |
| **LLM** | Large Language Model. | AI |
| **MIPS** | Millions of Instructions Per Second: mainframe capacity unit, often the basis of software licensing cost. | Mainframe |
| **MQ** | Message Queue; usually IBM MQ in mainframe estates. | Integration |
| **MSU** | Millions of Service Units: IBM's z/OS capacity unit used for software pricing. | Mainframe |
| **MTTR** | Mean Time To Recovery (or Repair). | Operations |
| **PDF** | Portable Document Format. | Format |
| **PIC** | COBOL PICTURE clause: declares a field's type, length, decimals and sign (e.g. PIC S9(11)V99). | Mainframe |
| **PL/I** | Programming Language One: IBM procedural language common on mainframes. | Mainframe |
| **PNG** | Portable Network Graphics. | Format |
| **PPTX** | PowerPoint Open XML presentation file. | Format |
| **PSD2** | Revised Payment Services Directive (EU 2015/2366): open banking and strong customer authentication. | Regulation |
| **RACI** | Responsible, Accountable, Consulted, Informed: responsibility matrix. | Governance |
| **REXX** | REstructured eXtended eXecutor: IBM scripting language. | Mainframe |
| **RPO** | Recovery Point Objective: maximum tolerable data loss, as time. | Operations |
| **RTO** | Recovery Time Objective: maximum tolerable downtime. | Operations |
| **SaaS** | Software as a Service. | Cloud |
| **SE** | Java Standard Edition. | Java |
| **SME** | Subject Matter Expert (domain expert reviewing extracted rules). | Governance |
| **SVG** | Scalable Vector Graphics. | Format |
| **SWIFT** | Society for Worldwide Interbank Financial Telecommunication: interbank messaging network. | Banking |
| **TL;DR** | Too Long; Didn't Read: summary. | General |
| **VSAM** | Virtual Storage Access Method: IBM mainframe file/record storage (KSDS, ESDS, RRDS). | Mainframe |
| **WEBP** | WebP image format (Google). | Format |
| **Y2K** | Year 2000 problem: two-digit year fields breaking at the century rollover. | Mainframe |
| **z/OS** | IBM's 64-bit mainframe operating system (z/OS Connect exposes mainframe programs as REST APIs). | Mainframe |
